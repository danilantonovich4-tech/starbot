# Telegram Stars Subscription Bot — прототип

Бот продаёт подписку на закрытый канал через **Telegram Stars** (валюта `XTR`,
встроена в Telegram — не нужен банковский эквайринг и комиссии платёжных систем).

## Возможности
- `/start` — выбор тарифа кнопками
- `/status` — проверка своей активной подписки
- Оплата через `send_invoice` с `currency="XTR"`
- После оплаты: продление срока подписки в БД + одноразовая инвайт-ссылка в канал
- После оплаты бот просит оценку 1–5 ⭐ и текстовый отзыв, сохраняет в БД и пересылает админам
- Фоновая задача каждый час проверяет истёкшие подписки и кикает пользователей из канала
- Уведомления админам о каждой оплате и каждом отзыве

## Установка

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

## Настройка

1. Создайте бота через [@BotFather](https://t.me/BotFather), получите токен.
2. Создайте приватный канал, добавьте бота **администратором** с правами:
   - Приглашать пользователей по ссылке
   - Блокировать пользователей (banChatMember)
3. Узнайте `channel_id` канала (например, через @userinfobot, перешлите сообщение из канала боту, или через getUpdates) — это отрицательное число вида `-100xxxxxxxxxx`.
4. Впишите токен и `channel_id` в `config.py` (или задайте переменные окружения `BOT_TOKEN`, `ADMIN_IDS`).
5. Отредактируйте тарифы в `PLANS` — название, цену в Stars, длительность.

**Важно про Stars:** отдельный provider_token для Stars не нужен — Telegram обрабатывает
платёж сам. Комиссия Telegram сейчас не берётся с продажи цифровых товаров через Stars
(на момент разработки), но перед запуском стоит свериться с актуальными условиями
в официальной документации Bot API, так как правила могут меняться.

## Запуск

```bash
export BOT_TOKEN="ваш_токен"
export ADMIN_IDS="123456789,987654321"
python bot.py
```

## Что доработать перед продакшеном
- Обработку возвратов (`refundStarPayment`) на случай спорных платежей
- Идемпотентность `successful_payment` (защита от повторной обработки одного и того же платежа, если апдейт прилетит дважды) — например, хранить `telegram_payment_charge_id`
- Логирование/алерты при сбоях `create_chat_invite_link` (например, если бот потерял права администратора)
- Более гибкие тарифы (несколько каналов на один тариф, пробный период и т.п.)
- Деплой с автоперезапуском (systemd/docker) и персистентным хранением `subscriptions.db`
- Юридические моменты: публичная оферта, условия возврата, налоговый режим — зависит от вашей юрисдикции
- FSM-состояния отзывов сейчас в `MemoryStorage` (оперативная память) — при перезапуске незавершённые отзывы теряются. Для продакшена — `RedisStorage` или хранение состояния в БД.
- **Никогда не публикуйте токен бота в чатах, переписке или публичных репозиториях.** Если токен где-то засветился — сразу перевыпустите его через @BotFather → Bot Settings → Revoke token, старый токен сразу перестанет работать.
